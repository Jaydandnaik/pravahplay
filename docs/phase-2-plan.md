## Exit criteria (brief §8 Phase 2)

1. `pnpm install && pnpm build && pnpm test` green from clean checkout on this machine.
2. docker-compose dev: `docker compose -f infra/compose.dev.yaml up -d` → api serves
   /healthz (200), /readyz (200 after migration), /metrics (Prometheus text); heartbeat row lands
   in Postgres; traces visible in Tempo; logs queryable in Loki; Grafana dashboard renders.
3. CI workflow file valid and pushed (repo creation = owner action, `gh` not installed).
4. Rollback path demonstrated: k3d local deploy via Helm → `helm rollback`/redeploy test.
5. Production (Oracle) deployment is **provisioning-blocked on owner** (account signup needs card +
   browser). IaC/playbooks are ready and the gate report states this gap explicitly.
